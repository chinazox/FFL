# Fresh Face Stock Manager

A standalone browser-based stock and professional ordering manager.

## Included
- Catalogue based on the supplied stock/pricing sheet.
- The three products highlighted red in the supplied sheet start as **Out of stock**:
  Cellucountour Body Massage Cream, Clearing Facial Tonic, Clear Skin Silver Fluid.
- Mark any product In stock / Running low / Out of stock.
- Optional stock quantity tracking.
- Search and filter by range/status.
- Add products to a professional-price order basket.
- Automatic order total.
- Generate copy-ready order text or download it as a `.txt` file.
- Export a JSON backup of your data.
- Data is stored locally in the browser with `localStorage`.

## Run it
Open `index.html` in a browser.

For Codespaces, from the project folder:
`python -m http.server 8000`

Then open the forwarded port.

## Important
The current stock quantities were not present in the supplied image, so quantities are left blank. The three red-highlighted products are pre-set as out of stock. You can update all statuses/quantities in the Products page.
