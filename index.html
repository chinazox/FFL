QUICK GUIDE

Editing your stock list

You only need to edit one file: data/products.json.

  1. Open data/products.json in GitHub/Codespaces.
  2. Edit a product, add a product, or change a range/status/price.
  3. Save the file and refresh the website.

Changing a category/range

Find the product and change the ranges list. You can have one range or several:

{
  "name": "Example Product",
  "ranges": ["Essential Range", "Masks"]
}

Changing stock

"professional": {
  "size": "125ml",
  "price": 42,
  "quantity": 3,
  "status": "In Stock",
  "specialOrder": false
}

For stock status use exactly In Stock, Running Low, or Out of Stock.

Special order

Set specialOrder to true when you do not need to keep the item on hand. A special-order item with zero stock will not be counted as a stock-out in the dashboard's ordering alert.

Adding a product

Copy an existing product object, give it a unique id, change the details, and paste it into the products array. If a product has no price in a mode, leave price as null and it cannot be added to the basket in that mode.

Product images

Optional. Put an image inside assets/images/ and set the product's image to something like assets/images/super-soft-cleanser.jpg.
